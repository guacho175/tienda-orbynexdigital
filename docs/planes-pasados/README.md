# Planes Pasados y Archivo Historico

Esta carpeta contiene documentos que ya no deben vivir en la raiz de `docs/` porque son planes ejecutados, reportes antiguos, prompts, preguntas o referencias historicas.

## Estructura

- `planes/`: planes ya ejecutados o reemplazados por documentacion tecnica vigente.
- `reportes/`: bitacoras y auditorias antiguas.
- `preguntas-y-prompts/`: preguntas cerradas, prompts de ejecucion y revisiones de decisiones.
- `historico/`: estado inicial del template y migraciones conceptuales antiguas.

## Regla

La raiz de `docs/` debe conservar solo:

- guias vigentes;
- indice general;
- handoff actual;
- documentacion tecnica modular;
- reportes que representen el estado actual.
