# Tareas activas

Esta carpeta contiene únicamente planes de trabajo largos que todavía están activos.

Formato:

```text
AAAA-MM-DD-<identificador-unico>-<descripcion>.md
```

Cada plan debe declarar `Estado`, alcance, archivos previstos, validaciones y criterio de cierre.
Al completarlo o abandonarlo, muévelo a `docs/archive/task-records/`.

Los cambios pequeños se describen en el issue, pull request o conversación correspondiente y no
requieren un archivo persistente.
